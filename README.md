🚀 Enterprise Hotel-Management-System Project – Cisco Packet Tracer

I recently designed and configured a Hotel Management System Network in Cisco Packet Tracer using a structured and scalable network design approach.
This project focuses on creating a reliable network infrastructure for different hotel departments, VLAN-based segmentation, wireless users, printers, and secure remote access.

In this simulation, I implemented key networking concepts including:
✅ OSPF Routing Protocol
 ✅ Inter-VLAN Routing using Router-on-a-Stick
 ✅ DHCP Configuration using Router as DHCP Server
 ✅ SSH Configuration for Secure Remote Access
 ✅ Switch Port Security
 ✅ WLAN Configuration using Cisco Access Points
 ✅ VLAN Creation and Network Segmentation
 ✅ IP Addressing and Subnetting
 ✅ End Device and Printer Connectivity

Through this project, I strengthened my practical understanding of enterprise network design, routing, switching, VLAN management, DHCP services, wireless networking, and basic network security.
This hands-on project helped me connect theoretical networking concepts with real-world implementation scenarios.
